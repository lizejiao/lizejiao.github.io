项目经验

一、58 同城 · AI 应用研发与研发效能（2021.12 ~ 2026.10）

租房业务线系统研发，主要负责 58 / 安居客（App、小程序、M 端、PC 端四端）房源列表、详情、大类页、推荐列表、微聊、隐私通话、来电通、预约看房、租房搬家、全链路日志 / 防爬、个性化推送、用户画像、香港站、标签运营活动、房源商业智能展示、房源验真、百亿补贴、房东省心租、房东委托、租赁保障、担保赎楼、履约支付、房金融记账等业务，同时负责 AI 研发效能基础设施建设 与 AI 业务落地，搭建 AI 工具链与知识库。

① AI 研发效能基础建设（这两年投入最多的地方）

  1. 自研 MCP 服务 —— 打通 AI 助手与企业内网

    • 让本地 AI 编程助手能够安全地操作企业内网沙箱、线上服务器
    • 提供文件上传、线上日志读取、堡垒机 / VPN 连通性检测、登录 token 自动获取等工具
    • 安全隔离设计： 堡垒机凭证由使用者本人保管，Agent 只校验存在性、绝不读取内容
    • 架构优化： 把高频日志读取从 MCP Tool 拆为独立 CLI 工具，减少 Schema 上下文占用、降低模型 Token 消耗；上传支持直连与中转双通道

  2. 研发自动化 Skill —— AI 自动化编码 / 部署 / 测试

    • 开发者只需提供一个接口 curl，AI 自动完成：环境与连通性检查 → 请求执行 → 返回结果字段级对比 → 源码定位接口实现 → 自动埋调试日志 → 通过 MCP 上传沙箱 → 等待生效 → 重新请求验证 → 循环调试 → 自动清理临时日志 → 输出调试报告
    • 代码推送前自动触发校验，不通过即拦截，为缺少 CI 的存量项目重建「质量门禁」
    • 亮点： 打通「AI 编码 → 自动测试 → 自动部署 → 自动验证 → 日志排障」全链路闭环，单接口迭代周期从半天级压缩至分钟级，修复类需求 100% 沉淀回归用例，已在多个核心项目推广为团队标准研发工作流

  3. RAG 智能知识库 —— 智能客服与线上问题自助排障

    • 把分散的业务文档、FAQ、历史工单、排障经验统一接入大模型，提供线上问题自助排查与客服问题解答
    • 完整链路： 文档接入与清洗 → 语义切片 → Embedding 向量化与索引 → 向量语义检索 + Elasticsearch 关键词检索双路召回 → 重排 → 基于上下文的问答与引用溯源，支持多轮追问
    • 亮点： 重复性咨询与线上排障交给知识库自助解决，缩短问题定位时间、降低人工答疑成本

② AI 业务商业化（AI 直接带来链接与收益增长）

  • AI 智能图像 / 首图优选： 试点城市上线房源首图智能优选，点击量提升 0.67%、点击转化率提升 2.87%、链接曝光占比提升 3.56%、增值房源链接占比提升 1.98%
  • AI 金牌经纪人推荐： 场景卡片新增经纪人智能展位，对比旧版本**展位转化率提升 46%**，全直销城市每日可新增约 200 条商机线索

③ 租客业务 —— 房源贴列表、详情、推荐、商业运营广告投放

  • 房源贴列表（四端统一）： 负责 58 / 安居客 App、小程序、M 端、PC 端四端房源列表与大类页，支持城市 / 商圈 / 价格 / 户型 / 朝向等多维筛选与非商业房源多维排序、小区卡片、推荐经纪人卡片、列表推荐语，以及防爬与全链路日志，保障高并发下稳定响应
  • 房源详情： 多模块异步加载、图片打标、商业保障（预约看房 / 租房搬家 / 保洁等）、小区位置地图、经纪人卡片、商业房源 AI 标签、微聊 / 隐私通话，持续优化埋点
  • 个性化推荐： 基于用户画像与浏览 / 点击 / 收藏行为搭建推荐列表召回与排序链路，融合规则召回与模型排序，支撑首页推荐、详情页「猜你喜欢」、列表页智能排序，提升房源点击率与转微聊率
  • 商业运营广告投放： 负责房源商业智能展示位、标签运营活动、百亿补贴、置顶 / 推广位等商业化投放链路，支持运营后台配置、广告位灰度、曝光 / 点击 / 转化埋点与计费归因，直接拉动 B 端房源推广收入

④ 发布 / 公寓业务 —— 房源核验、政府核验、省心租

  • 房源发布与核验： 负责房东 / 经纪人发布房源链路，落地房源验真能力（图片真实性、价格合理性、位置 GPS 校验、联系方式反作弊），减少虚假房源与重复贴
  • 政府核验与网签备案： 对接各地住建 / 租赁监管平台，实现房源信息政府核验、租赁合同网签备案与备案状态回传，满足监管合规要求
  • 省心租（租房保洁）： 主导房东委托 + 保洁履约链路，支持在线下单、平台派单、预约时间、履约签到、完工确认与评价，联动支付与对账完成服务闭环
  • 房东委托与租赁保障： 落地房东委托、租赁保障等增值业务，打通房东端委托管理、租客端保障权益展示与理赔流程

⑤ 房交易业务 —— 主导房金融账本核算

现金赎楼业务流程主链路为：授信 → 用信 → 合同借据（签约 → 放款 → 还款）→ 清偿 → 过户 → 核抵。核心功能包括借据与放款、还款计划、利息与罚息计算、虚拟账户账本、收益核算、还款冲账（罚息 → 费用 → 利息 → 本金 优先级）、与资金平台 / 渠道 / 财务自动对账与日终跑批，保证账实一致。

二、龙湖集团 · 平台中台与统一服务（2021.04 ~ 2021.11）

集团 IT 中心平台中台团队，为地产、商业（天街）、长租公寓（冠寓）、智慧服务等多条业务线提供统一后台与基础技术服务。

  • 统一后台管理中台： 前后端分离 + 服务分层设计，统一权限模型、菜单路由与操作审计；沉淀 Elasticsearch 检索组件、RabbitMQ 延迟队列组件、统一异常处理与参数校验 starter，新业务接入从周级缩短到天级；接入全链路追踪与 ELK 日志平台，故障定位时间显著缩短
  • 统一消息推送平台： 打通极光推送 + 集团短信双通道，建设统一消息网关，支持多租户、多 App 接入，提供点对点 / 批量推送、站内信、未读红点、模板消息，支持推送频控、到达回执与失败重试

三、包银消费金融 · 互联网金融高并发交易 / 核算系统（2017.05 ~ 2021.04）

经银保监会批准设立的全国性持牌消费金融公司（包商银行旗下），后重组更名为蒙商消费金融。业务以「自营 + 助贷联合贷」为主，深度对接京东金条、微粒贷、去哪儿、分期乐、小米、奇富等互联网流量渠道；截至 2021 年初累计注册客户 **1200 万+**、累计放款 320 亿。

  • 核心交易系统： 借还款全生命周期账务与虚拟账户体系，基于分布式锁 + 幂等设计保证资金账务强一致；系统可支撑每分钟 640+ 笔、每小时 2 万笔授信申请，贷后每小时批处理 17 万客户，日终借据处理量 152 万笔
  • 财务核算与对账： 解析交易流水按借贷规则自动生成会计分录推送核心财务系统；2019 年主导自研重构，新增银企对账、渠道对账、资金对账自动化，差异自动挂账与告警，显著提升月结 / 年结效率
  • 渠道对接与联合贷款： 对接京东、微粒贷、去哪儿、分期乐、小米等多家助贷渠道，抽象渠道适配层；参与联合贷款（协议路由、还款计划拆分、资方授信分账）建设，峰值 800 笔 / 分钟
  • 清结算与监管报送： 参与清结算工作台建设（收付款、退款、转账审核、资金划拨）；按监管口径生成 1104 / EAST 等报送报文，保障账务合规与数据可追溯
